# Exporteren kan nu ook per project

Sinds deze week kun je je gegevens per project exporteren. Dat scheelt een hoop klikwerk.

Tot nu toe kreeg je altijd de hele werkruimte in één bestand. Handig als je alles wilde archiveren, maar niet als je één project moest doorsturen naar een klant. Dat vroegen jullie vaak, en terecht.

Hoe werkt het? Open een project, klik rechtsboven op Exporteren en kies je formaat. Er zijn er drie: CSV, JSON en een pdf-rapport. De export draait op de achtergrond, dus je kunt gewoon doorwerken. Je krijgt een mailtje zodra het bestand klaarstaat.

Een paar dingen om te weten. Gearchiveerde projecten doen niet mee, tenzij je ze eerst terugzet. Bestanden groter dan twee gigabyte splitsen we automatisch. En wie met een gedeelde werkruimte werkt, exporteert alleen wat hij zelf mag zien.

Probeer het eens en laat gerust weten wat je ervan vindt. We horen het graag.
